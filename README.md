# Vendor Payment Management System

A full-stack CRUD application built using FastAPI and PostgreSQL for managing vendor information.

## Features

- Create Vendor
- Read Vendor List
- Update Vendor Information
- Delete Vendor
- REST API using FastAPI
- PostgreSQL Database Integration
- SQLAlchemy ORM
- Frontend Dashboard UI

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

### Frontend
- HTML
- CSS
- JavaScript
